# @roundMe — page d'accueil (GitHub Pages)

Ces fichiers forment la page d'accueil de @roundMe (DEC-40). Ils se déposent tels quels dans un dépôt GitHub public, avec GitHub Pages activé sur la branche `main`, dossier racine.

| Fichier | Rôle |
|---|---|
| `index.html` | Affiche l'application Apps Script dans un cadre ; transmet les paramètres de l'adresse. |
| `manifest.webmanifest` | Nom et icônes pour « Ajouter à l'écran d'accueil » (Android). |
| `icone-180.png` | Icône pour l'écran d'accueil de l'iPhone. |
| `icone-192.png`, `icone-512.png` | Icônes Android. |
| `icone-32.png` | Icône de l'onglet du navigateur. |
| `sw.js` | Rend la page installable ; ne met rien en cache. |

Aucune donnée, aucune clé : la page ne contient que l'adresse publique de l'application.
